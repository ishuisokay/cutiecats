# A Little World Made Just For You 🐾🌸

A personalized, interactive apology and friendship appreciation website crafted with love for a girl who adores cats and dogs.

---

## ✨ Features & Sections

1. **🌸 Welcome Screen ("Hey, You! 🐾")**
   - Cute animated kitten and puppy characters with bobbing ears, blinking eyes, and wagging tails.
   - Interactive tap reactions with purrs, yaps, and floating heart particles.
   - Smooth "Open Your Surprise" button with pastel confetti that gently glides to the apology.

2. **💌 A Heartfelt Apology**
   - Interactive stationery envelope with wax seal animation.
   - Sincere, emotional, and honest explanation about repeatedly unsending messages — addressing overthinking without melodrama.
   - Thoughtful comparison cards: *What was in my head* vs *What you experienced* vs *What I promise now*.
   - Interactive "Pinky Promise" seal button with celebratory sparkles.

3. **🐾 Cat & Dog Paradise**
   - **Virtual Pocket Companion**: Choose between **Biscuit the Pup 🐶** and **Mochi the Cat 🐱**.
   - Interactive happiness meter (0% - 100%) with Pet, Feed Treat, Play Toy, and Cozy Nap actions.
   - Curated gallery of 8 adorable furry friends with filters (*All, Cuddle Kitties, Happy Pups, Sleepy Loaves*), quirky traits, quotes, and interactive heart buttons.

4. **🎁 Little Happiness**
   - **The Smile Dispenser 🍬**: A sweet compliment and affirmation generator that dispenses sincere reminders with card flips and sound effects.
   - **Clickable 3D Flip Surprise Cards**: "The Science of Furry Comfort", "Lifetime Friendship Voucher", "Gentle Soul Reminder", and "Golden Retriever Life Rules".
   - Shower hearts and confetti interactive button.

5. **💖 Final Friendship Letter**
   - Sincere friendship appreciation message celebrating her kindness and warmth.
   - The ending quote:
     > *"I know words cannot fix everything, but I hope this little corner of the internet makes you smile."*
   - Interactive "Did this make you smile?" feedback buttons.
   - "Send a Virtual Hug Back 🤗" button with live floating hearts.

6. **🎵 Built-in Cozy Web Audio API Soundscape**
   - Zero external audio files required — 100% reliable and offline-safe.
   - Ambient pastel lofi chime melody (toggle on/off).
   - Pleasant chime, pop, purr, and woof sound effects (with mute option).

## 🚀 Running the Project

```bash
# Navigate to the project directory
cd /Users/premludhani26/.gemini/antigravity/scratch/little-world-for-you

# Start the development server
npm run dev

# Or build and preview the production version
npm run build
npm run preview
```

Open your browser at `http://localhost:5173` (or the port displayed in your terminal).
